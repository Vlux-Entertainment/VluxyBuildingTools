# Hotkeys

The keys follow Blender. The **Hotkeys** tab (F1) shows this same list inside Studio.

The plugin leaves **W A S D Q E F** and **Shift** to Studio, so flying the camera, focusing and
multi-select keep working. Ctrl and Alt are only used for the keys below, so Studio's own shortcuts
keep working too.

## Tools

| Keys | What it does |
|---|---|
| **Ctrl + 1–7** / **Ctrl + 0** | Pick a tool; again to stop |
| **Alt + 1–0** | Pick a tool option |
| **Ctrl + Scroll** | Previous or next tool or prop section |
| **Alt + Scroll** | Previous or next option |

## Drawing

| Keys | What it does |
|---|---|
| hold **Shift** | Snap to the fine grid |
| **X** / **Y** / **Z** | Lock to an axis; again to unlock |
| **Alt + X** / **Y** / **Z** | Lock to the plane across it |
| **0–9** **.** | Type an exact amount |
| **[** **]** | Lower or raise the height |
| **Enter** / **Click** | Confirm |
| **Esc** / **Right-click** | Cancel, or stop the tool |

## Move & edit

| Keys | What it does |
|---|---|
| **G** | Grab the selection |
| **R** | Rotate the selection |
| **C** | Scale the selection |
| **Arrows** | Turn 90° while rotating |
| **V** | Duplicate and grab |
| **T** | Extrude the face under the cursor |
| **Ctrl + M** then **X/Y/Z** | Mirror on that axis |
| **O** then **X/Y/Z** | Turn 90°; Alt for -90° |

With the Prop tool on, **R** turns the prop 90° instead of rotating the selection.

## Show & hide

| Keys | What it does |
|---|---|
| **H** | Hide selected parts, just for you |
| **Alt + H** | Unhide everything |
| **I** | Hidden parts as ghosts on or off |
| **P** | Themes on or off |
| hold **P** + **Scroll** | Switch the theme |
| **L** | Surface grid on or off |
| **Alt + L** | Camera light on or off |

Holding P and scrolling switches the theme without turning themes off when you let go.

## Panel

| Keys | What it does |
|---|---|
| **N** | Show or hide the panel |
| **Tab** / **`` ` ``** | Next or previous tab |
| **F1** | Open the Hotkeys tab |
| **W A S D Q E F** | Left to Studio's camera |

## Turning the hotkeys off

The **Blender hotkeys** switch at the top of the Hotkeys tab turns these keys off. **Esc**,
**Enter**, **[** and **]** still work, and so does **R** to turn a prop. Typed numbers are off too.
If you press a tool key (Ctrl+number) while the hotkeys are off, the status line tells you why
nothing happened.
