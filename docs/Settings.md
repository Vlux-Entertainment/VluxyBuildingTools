# Settings

The **Settings** tab holds the settings that apply to every tool, in six cards. Your settings are
saved with your Studio, not with the place. Hover any row for a short description, and right-click
a number to put it back to its default.

## Snapping

| Setting | Default | What it does |
|---|---|---|
| **Grid Snap** | 4 | The grid points snap to, in studs. |
| **Precise Grid Snap** | 0.25 | The finer grid used while you hold Shift. |
| **Snap to parts** | On | Snap points to corners and edges of nearby parts. |
| **Part snap distance** | 1 | How close the cursor must be to snap to a part. |

## Standard sizes

The sizes new builds start from.

| Setting | Default |
|---|---|
| **Wall height** | 12 |
| **Wall thickness** | 1 |
| **Doorway width** | 4 |
| **Doorway height** | 7.75 |
| **Face extend length** | 8 |

Changing a standard size changes the matching field on the Build tab, unless you set that field to
something else there. A field you changed by hand keeps your value.

## Interface

| Setting | Default | What it does |
|---|---|---|
| UI color | Orange | The panel's accent color: Orange, Red, Pink, Purple, Blue, Teal, Green or Yellow. |
| **Arrow step** | 0 | How much the + and - buttons change a number. 0 uses each field's own step. |
| **UI animations** | On | Buttons pop when clicked or picked. |
| **Animation intensity** | 0.5 | How big the pops are. |
| **Zebra rows** | On | Shade every other row so values line up with their labels. |
| **Tooltips** | On | Show descriptions when you hover. |
| **Tooltip delay** | 0.35 | How long to hover, in seconds, before a description shows. |

## Viewport

| Setting | Default | What it does |
|---|---|---|
| **Previews use the UI color** | On | Build previews and folder outlines take the UI color, not orange. |
| **Hint bar** | On | Show the active tool's keys at the bottom of the 3D view. |
| **Prop rotation** | On | The hovered or picked prop picture slowly turns. |

## Sound

| Setting | Default | What it does |
|---|---|---|
| **Play sounds** | On | Small sounds for clicks and tools. Only you hear them. |
| **Sound volume** | 0.5 | How loud they are. |

## Reset

**Reset settings** puts every setting on this tab back to its default. It does not touch tool
options, the Display tab or the hotkeys switch, and it does not change anything you built.
