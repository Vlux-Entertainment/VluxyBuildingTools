Settings

The Settings tab holds the settings that apply to every tool, in six cards. Your settings are saved with your Studio, not with the place. Hover any row for a short description, and right-click a number to put it back to its default.

Snapping​

SettingDefaultWhat it does
Grid Snap4The grid points snap to, in studs.
Precise Grid Snap0.25The finer grid used while you hold Shift.
Snap to partsOnSnap points to corners and edges of nearby parts.
Part snap distance1How close the cursor must be to snap to a part.

Standard sizes​

The sizes new builds start from.

SettingDefault
Wall height12
Wall thickness1
Doorway width4
Doorway height7.75
Face extend length8

Changing a standard size changes the matching field on the Build tab, unless you set that field to something else there. A field you changed by hand keeps your value.

Interface​

SettingDefaultWhat it does
UI colorOrangeThe panel's accent color: Orange, Red, Pink, Purple, Blue, Teal, Green or Yellow.
Arrow step0How much the + and - buttons change a number. 0 uses each field's own step.
UI animationsOnButtons pop when clicked or picked.
Animation intensity0.5How big the pops are.
Zebra rowsOnShade every other row so values line up with their labels.
TooltipsOnShow descriptions when you hover.
Tooltip delay0.35How long to hover, in seconds, before a description shows.

Viewport​

SettingDefaultWhat it does
Previews use the UI colorOnBuild previews and folder outlines take the UI color, not orange.
Hint barOnShow the active tool's keys at the bottom of the 3D view.
Prop rotationOnThe hovered or picked prop picture slowly turns.

Sound​

SettingDefaultWhat it does
Play soundsOnSmall sounds for clicks and tools. Only you hear them.
Sound volume0.5How loud they are.

Reset​

Reset settings puts every setting on this tab back to its default. It does not touch tool options, the Display tab or the hotkeys switch, and it does not change anything you built.
