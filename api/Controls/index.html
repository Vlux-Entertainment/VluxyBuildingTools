Controls

The panel's controls: cards, text, buttons, number fields, switches, a slider and choice rows. Each control that shows a setting reads it from the Store reactively and writes it back through the Store, so it always shows the saved value and every change is saved.

Every control takes a Visible that may be a function; the control shows only while it returns true. That is how the panel shows just the options of the active tool. A control may also take Locked: while it returns true the control is greyed, takes no input, and its hover text names the working folder's admin, who alone may change it.
