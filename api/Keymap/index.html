Keymap

The Blender-style hotkeys. Resolve turns a key press into an action name; the plugin decides what the action does. Ctrl is only used for Ctrl+M and the Ctrl+number tool picks, and Alt for Alt+H, Alt+L, the plane locks and the Alt+number options, so Studio's own shortcuts keep working. W A S D Q E F and Shift are never taken: Studio uses them to fly the camera, focus and multi-select.
