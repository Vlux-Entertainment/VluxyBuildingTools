Display

The viewport aids that change how the map looks: pastel colors, the surface grid and hidden parts. It owns the three Core modules, mirrors their state into AppState for the panel, and remembers whether pastel and grid should come back on by themselves.

Settings that restyle what is already in the map (theme, grid color and tile size, ghost transparency) are watched here, so changing them anywhere restyles the map. Only the folder's admin restyles it; everyone else sees the admin's changes, which replicate.
