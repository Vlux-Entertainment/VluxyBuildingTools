Colors

The reversible color theme toggle. It gives every Part a color from the picked theme and remembers the original in an attribute, so the colors survive a crash and can always be restored. The attribute names match the old standalone Greybox plugin on purpose.

Properties​

Themes​

</>
Colors.Themes: {string}

The color themes that can be picked; the list itself lives in Settings.Themes.

Sweep​

</>
Colors.Sweep(self: Colors) → ()

Gives every part in the working folder that missed its color one, so a part made by a cut, a union or any other path is never left plain. It runs at the end of each plugin edit.

Retheme​

</>

RestoreOnUnload​

</>
Colors.RestoreOnUnload(self: Colors) → ()

Restores the original colors when the plugin unloads, as one undo step. A crash skips this; the saved attributes cover that case.
