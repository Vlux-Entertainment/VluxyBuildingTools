AdminRules

Who is the admin of a working folder. Each user with the plugin open on the folder leaves a heartbeat and the time they joined as attributes on it; these rules read those values and decide who is present, who is admin, and whether an admin request still stands. Plain data only.

The admin is whoever the folder names while they are present. When they are gone, the user present the longest takes over (ties go to the lower user id), and a user alone is always admin. An idle admin keeps admin until another present user takes it over.
