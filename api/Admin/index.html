Admin

Who is working in the working folder, and which of them is its admin. While the panel is open, this user leaves a heartbeat and a joined time as attributes on the folder (AdminRules names them); the admin alone changes the shared map settings and hides parts. These attributes are not undoable edits, so they are written outside any recording and cleared on leaving. This user's last activity is published too, about once a minute, so teammates may take over an idle admin.

The rules live in Pure/AdminRules. Only the user who should become admin writes the change, so two clients never race to claim it. The result is mirrored into AppState for the panel.
