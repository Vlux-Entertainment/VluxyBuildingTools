Overlay

Everything the tools draw into the viewport: the box previews, the construction grid, wedge outlines, the measuring line, the drag handles and the floating number. All of it lives in CoreGui, so only the person using the plugin sees it and nothing is saved in the place.

Functions​

Sweep​

</>
Overlay.Sweep() → ()

Destroys everything the overlay ever drew, found by its tag, so a leftover from an earlier load, a reload or a crash cannot stay in the viewport.
