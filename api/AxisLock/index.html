AxisLock

Blender-style axis locking for a drag. A lock keeps the dragged point on one world axis, or, with the plane flag, on the plane that axis is perpendicular to. The ray maths uses plain tables so it runs under Lune.

Finds where along a line the mouse ray passes closest to it, in units of the line's direction. Returns nil when the ray runs parallel to the line, since there is no single answer then.

</>

Moves a point onto a lock. Axis lock: only the locked component follows raw. Plane lock: the locked component stays at origin and the other two follow raw.
