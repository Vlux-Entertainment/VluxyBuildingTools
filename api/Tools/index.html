Tools

The list of building tools: id, label, icon glyph and number hotkey. The panel draws its tool grid from this and the status bar names the active tool from it, so the two never disagree.

Types​

Tile​

</>
interface Tile {}

One tile of the tool grid. A tile with several Modes is a group: picking it starts the mode used last, and the panel offers the others as options. A plain tile has one mode with its own id.

Properties​

Instructions​

</>
Tools.Instructions: {[string]: string}

How to use each tool, by tool id: the status line shows it when the tool starts and after each build.
