Hidden

Part hiding, shared with the whole team. A hidden part carries the VluxyBT_Hidden tag and is locked, both of which replicate; every client watches the tag and makes tagged parts invisible on its own screen through LocalTransparencyModifier. Showing hidden parts as ghosts stays local.

Hides the parts for everyone: tags and locks them, remembering the lock they had. Run it inside an edit, so it is one undo step.

UnhideAll​

</>
Hidden.UnhideAll(self: Hidden) → number--

how many were hidden

Brings back every hidden part for everyone, including parts hidden by an older version or replaced by a union since, which are found by the attribute that remembers their lock. Run it inside an edit when the user asks for it, so it is one undo step.
