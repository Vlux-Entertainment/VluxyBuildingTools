Engine

The engine behind every point-to-point tool: walls, rooms, corridors, stairs, vents and the rest.

The engine owns the drawing: the first point, the mouse point, axis locks, the Y height drag, the rise stage of stairs and sloped vents, typed lengths and chaining one segment onto the next. A shape (see Shape) only says what is different about it: where its points may land, what it builds between two points, and what to do after building. Turn a shape into a tool with Engine.Tool(shape).

The flow, with the state field that holds each step:

  1. Before the first click the cursor is shown where a build would start (Current).
  2. The first click fixes First. Moving the mouse previews the build from First to Current.
  3. A shape with Rise takes one more click: the next one fixes the run and starts the rise (Rise), and the mouse then sets the height.
  4. The next click builds. A chaining shape keeps going from the end point (Chained); the last segment is kept in Previous so the next one can join it.

interface Built {

the Model (or loose Part) placed

Model: Model?--

Placed when it is a Model

Segment: Vector3--

the flat vector from the first point to the end point

Joint: Vector3--

the first point, where the segment meets the one before it

Previous: Segment?--

the segment before this one, if chained

}

What a shape's Commit gets after its build was placed, inside the undo step.
