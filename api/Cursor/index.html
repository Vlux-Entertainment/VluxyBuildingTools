Cursor

Everything the tools ask about the mouse: where it points, which modifier keys are held, and how a point snaps to the grid and to nearby parts.

Mark is the snap marker of the preview being drawn. The tool runner clears it before each preview, the snapping helpers set it when they snap, and the runner draws it afterwards.
