Settings

The tool settings and their saved form. Everything here is plain data, so it runs under Lune.

Properties​

Standards​

</>
Settings.Standards: {{string}}

The values a tool field can override, as { field, standard, override flag }.

Page​

</>
Settings.Page: {string}

The settings shown on the Settings tab, which its Reset puts back; tool, display and hotkey settings are left alone.

Themes​

</>
Settings.Themes: {string}

The color themes, in the order the panel shows them.

Shared​

</>
Settings.Shared: {{
Key: string,
Name: string
}}

The settings everyone working in one folder shares, as { Key, Name }. They are kept in attributes on the working folder, so the whole team sees the same viewport. Only the folder's admin changes them.

Functions​

ThemeName​

</>
Settings.ThemeName(value: any) → string?--

the theme the value names, ignoring case, or nil when it names none

OverrideFlag​

</>
Settings.OverrideFlag(
key: string--

a setting

) → string?--

the override flag that remembers a tool field differs from its standard, if the key has one

Apply​

</>
Settings.Apply(
settings: Settings,
key: string,
value: any
) → ()

Writes one value the way the panel does: a tool field that has a standard remembers whether it now differs from it, and a changed standard flows into every field that is not overridden.

Differences​

</>
Settings.Differences(
settings: Settings,
read: (key: string) → any--

the folder's stored value of a shared setting

) → {string}--

the names of the shared settings the folder holds a different value for

VentOuter​

</>
Settings.VentOuter(settings: Settings) → number--

the outside width of a vent duct

VentSize is the clear space inside a vent; the sheets sit outside it.

VentHole​

</>
Settings.VentHole(settings: Settings) → number--

the side of the square a Vent Hole cuts: the vent's inside size, or its outside size when VentHoleFit is "Outside"

Sync​

</>
Settings.Sync(settings: Settings) → ()

Gives every field that is not overridden the standard value, and clears an override that now matches its standard.

Load​

</>
Settings.Load(
saved: any--

whatever the plugin settings store returned

) → Settings

Copies every saved value whose type matches the default's type over the defaults. Unknown keys and values of the wrong type are dropped, so an old or damaged save cannot break the plugin.
