Runner

Runs the active tool. It is the only caller of the tool functions in Tools/Types: it starts and stops tools, draws each preview, and hands the tool its clicks and keys.

It also remembers, for every tile with several modes, which mode was used last, so picking the tile again starts that one, and which tool was used last, so Enter can bring it back.

A tool error never escapes: a failing preview stops the tool and says why.
