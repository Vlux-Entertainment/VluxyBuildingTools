Snapper

Snaps a point to the corners and edges of the parts already built nearby, like Roblox's own building tools do. It works on the outline of each part seen from above, so the height of the point is never changed.

Types​

one end of the middle line, at the foot of the wall

Axis: Vector3--

The middle line of a wall along its foot: a thin, upright part whose long side is level.

The two ends of a vent, where the openings are and which way each looks out.

RememberVentEnds​

</>
Snapper.RememberVentEnds(
model: Instance,--

the vent

ends: VentEnds,
pivot: CFrame--

the model's pivot now

) → ()

Records a vent's ends on its model. They are kept relative to the model's pivot, so they stay on the openings when the vent is moved or turned, and in world space too for older readers. The caller fixes the pivot first (see FixPivot), so it cannot drift when the vent's sheets change.

FixPivot​

</>
Snapper.FixPivot(model: Model) → CFrame--

the pivot

Sets a vent model's pivot to where it is now. A model whose pivot was never set can take it from its parts, so it would move when a corner stretches the vent's sheets and carry the recorded ends off the openings; a set pivot only moves with the whole vent.

Reads a vent's ends through a getter, so it works on any attribute source. Ends relative to the pivot are used only on vents whose pivot was fixed when they were recorded; others, including vents whose pivot may have drifted, use their world ends.

TopCenter​

</>
Snapper.TopCenter(
part: BasePart,
point: Vector3,--

where the cursor hit the top

grid: number,
endReach: number--

how close to an end counts as the end

) → Vector3?--

the point on the centre line, or nil when the part is not thin

Moves a point on the top of a thin part, such as a wall, onto its centre line, so a wall built on top of a wall sits on it instead of beside it. Along the part it snaps to its ends or its middle, else to the grid measured from one end.

Doorway​

</>
Snapper.Doorway(
point: Vector3,
radius: number--

how far from the middle of the opening still counts

) → Doorway?

Finds a doorway made by the Additive tools near the point: a rectangular or arched opening that reaches the floor. The result is the middle of the opening on the face of the wall the point is on, with the direction pointing away from that face, so a corridor can start there.
