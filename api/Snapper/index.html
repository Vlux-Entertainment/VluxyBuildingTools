Snapper

Snaps a point to the corners and edges of the parts already built nearby, like Roblox's own building tools do. It works on the outline of each part seen from above, so the height of the point is never changed.

Functions​

Find​

</>
Snapper.Find(
point: Vector3,--

the point to move, already snapped to the grid

radius: number--

how far away a corner or edge can be and still attract the point

) → (
Vector3,--

the snapped point, or the same point when nothing was near

boolean,--

whether it moved to a part

BasePart?--

the part it moved to

)

Finds the nearest corner of a nearby part within the radius, else the nearest edge within most of it. Only the working folder is searched when one is set.

Vertex​

</>
Snapper.Vertex(
point: Vector3,--

where the cursor hit

radius: number
) → (
Vector3,--

the corner, or the same point when none is near

boolean--

whether it moved to a corner

)

Finds the nearest of the eight corners of any part within the radius, in all three dimensions. The Measure tool uses it so a distance starts and ends exactly on a vertex.

VentEnd​

</>
Snapper.VentEnd(
point: Vector3,
radius: number
) → (
Vector3?,--

the middle of the opening

Vector3?--

the direction pointing out of the vent

)

Finds the open end of a vent built by this plugin near the point. Each vent model records its two ends in attributes so a new vent, or a cover, can start exactly on one.

VentConnect​

</>
Snapper.VentConnect(
point: Vector3,--

where the cursor hit

radius: number,--

how far from the middle line still counts

step: number--

the spacing of the points along a vent

) → (
Vector3?,--

the point on the middle line

Vector3?,--

the way out of the vent when the point is an open end, else nil

Instance?--

the vent model the point is on

)

Finds a connection point on a vent built by this plugin: either open end, or any spot along its middle line, snapped to the step. A new vent or a shaft can start from any of them.

VertexNear​

</>
Snapper.VertexNear(
point: Vector3,--

where the cursor hit

mouse: Vector2,--

the mouse in screen coordinates

pixels: number--

how close on screen counts

) → (
Vector3,--

the corner, or the same point when none is near

boolean--

whether it moved to a corner

)

Finds the corner of a nearby part that sits closest to the mouse on the screen, within a few pixels. Unlike a distance in studs, this only grabs a corner when the cursor is really on it.

TopCenter​

</>
Snapper.TopCenter(
part: BasePart,
point: Vector3,--

where the cursor hit the top

grid: number,
endReach: number--

how close to an end counts as the end

) → Vector3?--

the point on the centre line, or nil when the part is not thin

Moves a point on the top of a thin part, such as a wall, onto its centre line, so a wall built on top of a wall sits on it instead of beside it. Along the part it snaps to its ends, else to the grid measured from one end.

Doorway​

</>
Snapper.Doorway(
point: Vector3,
radius: number--

how far from the middle of the opening still counts

) → Doorway?

Finds a doorway made by the Additive tools near the point: a rectangular or arched opening that reaches the floor. The result is the middle of the opening on the face of the wall the point is on, with the direction pointing away from that face, so a corridor can start there.
