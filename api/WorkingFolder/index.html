WorkingFolder

The working folder: the one Folder in Workspace the plugin builds in and changes. Nothing outside it is edited.

Picking one is a small flow: start picking, click or select a Folder (it is outlined and waits), then confirm. A folder must carry the VluxyBT_Map tag; one without it is shown in the panel with how to tag it, and picked as soon as it is tagged. When the folder already holds shared settings (see Settings.Shared) that differ from the user's, the user chooses whose to keep before it becomes the working folder; someone joining teammates already there simply takes the folder's. While it is the working folder, the admin's changes are written to it, and everyone takes over what is written to it.
