ArrayStep

The step between copies of an array, as Blender's Array modifier works it out: a relative offset in multiples of the object's own size plus a constant offset in studs, each switched on or off. Plain numbers, so it runs under Lune.

Properties​

MaxCount​

</>
ArrayStep.MaxCount: number

The most objects an array makes, counting the original.
